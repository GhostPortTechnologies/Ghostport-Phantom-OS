# gp-speedtest — Speed Test

## Summary
Native terminal speed test using curl against Cloudflare edge servers. No external dependencies — uses only curl and ping.

## Quick Start
1. Open **Start Menu > MONITOR > Speed Test**
2. Tests latency, download (3 runs), and upload (2 runs)
3. Review speed grade and breakdown

## Flags
| Flag | Description |
|------|-------------|
| `--json` | JSON output for scripting |
| `--quick` | Single run each (faster, less accurate) |

## Test Details
| Test | Method | Runs |
|------|--------|------|
| Latency | `ping -c3 1.1.1.1` | 1 |
| Download | 25MB from Cloudflare edge | 3 |
| Upload | 5MB random data to Cloudflare | 2 |

## Grading
| Mbps | Grade | Label |
|------|-------|-------|
| 200+ | A+ | Blazing |
| 100+ | A | Fast |
| 50+ | B | Good |
| 20+ | C | Moderate |
| 5+ | D | Slow |
| <5 | F | Slow |

## How It Works
Downloads test files from `speed.cloudflare.com` and measures throughput via curl's `%{speed_download}` metric. Upload uses random data generated by `/dev/urandom`. Shows exit IP and current privacy mode. Best run is highlighted with a star.
