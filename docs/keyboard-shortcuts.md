# Phantom OS Keyboard Shortcuts

## Desktop

| Shortcut | Action |
|----------|--------|
| Super + Enter | Open Terminal |
| Super + E | Open File Manager |
| Super + B | Open Browser |
| Super + L | Lock Screen |
| Super + G | Toggle Widget |
| Super + Space | Start Menu |
| Alt + Tab | Switch Windows |
| Alt + F4 | Close Window |
| Print | Screenshot (Region) |
| Shift + Print | Screenshot (Full) |

## Window Management

| Shortcut | Action |
|----------|--------|
| Super + Left | Snap Window Left |
| Super + Right | Snap Window Right |
| Super + Up | Snap Window Top |
| Super + Down | Snap Window Bottom |
| Alt + Left | Move Window Left |
| Alt + Right | Move Window Right |

## Mouse

| Action | Result |
|--------|--------|
| Right-click desktop | App Menu |
| Middle-click desktop | Window List |
| Left-click desktop | Deselect |
